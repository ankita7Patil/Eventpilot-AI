# EventPilot AI Demo Script

## Opening

"Students register for many hackathons, internships, contests, and webinars, then miss updates, mentor calls, or submission deadlines. EventPilot AI is an autonomous opportunity intelligence agent that handles that workflow."

## What To Show

1. Start the FastAPI backend.
2. Open the frontend.
3. Paste a real public event URL.
4. Click `Analyze`.
5. Explain the workflow running behind the UI:
   - Monitor Agent scraped the page.
   - Research Agent generated an AI briefing.
   - Recommendation Agent ranked strategy.
   - Scheduling Agent built the timeline.
   - Alert Agent created proactive reminders.
6. Show the real activity feed returned by the backend.
7. Ask the chat agent: `What is urgent and what should I prepare?`

## Closing

"This is not a chatbot. The chat is only one interface. The product value is the autonomous workflow: EventPilot researches, decides, stores, and creates reminders before the user asks."
